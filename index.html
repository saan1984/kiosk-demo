A small outdoor gear shop. This is the whole book's app.

Live demo from the book WebMCP in Practice. Everything a shopper can do here works normally. The tool panel further down is real: it lists what an agent could call right now, and redraws itself as the cart changes.

Checking which WebMCP this browser is running…

A browser extension or other outside agent generally can't call these tools. The JavaScript surface they're registered through is meant for agents running in the page, and Chrome's own built-in agent reaches native tools by a separate route. Bridging a tab out to another process needs @mcp-b/transports, which Kiosk deliberately does not use. The book covers that boundary in §7.5 and §9.4.
